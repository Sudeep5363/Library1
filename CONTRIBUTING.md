# Contributing to Library Management System

Thank you for your interest in contributing! We welcome all contributions.

## How to Contribute

### Reporting Bugs

1. Check if the bug already exists in [Issues](https://github.com/Sudeep5363/library-management/issues)
2. Create a detailed bug report including:
   - Steps to reproduce
   - Expected behavior
   - Actual behavior
   - Screenshots/browser console errors
   - Your browser and OS

### Feature Requests

1. Suggest features via [Issues](https://github.com/Sudeep5363/library-management/issues)
2. Describe the use case and expected behavior

### Code Contributions

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/YourFeature`
3. Make your changes
4. Test thoroughly in multiple browsers
5. Commit with clear messages: `git commit -m 'Add: YourFeature'`
6. Push: `git push origin feature/YourFeature`
7. Open a Pull Request

## Code Style Guidelines

- Use semantic HTML
- Follow CSS naming conventions (BEM or similar)
- Write clean, documented JavaScript
- Use 4 spaces for indentation
- Keep lines under 120 characters
- Add comments for complex logic

## Testing

Before submitting:
- Test in Chrome, Firefox, Safari, and Edge
- Test on mobile (responsive design)
- Check console for errors
- Verify no performance issues
